# Bank Loan Analytics Dashboard
## Project Overview
This project presents an interactive Power BI dashboard for analyzing bank loan data. It provides insights into loan applications, funded amounts, repayments, interest rates, debt-to-income ratio, loan purposes, and customer demographics.
---
## Dashboard Features
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio
- Monthly Loan Application Trend
- State-wise Loan Applications
- Loan Applications by Purpose
- Home Ownership Analysis
- Loan Term Analysis
- Good vs Bad Loan Performance
- Interactive Filters
---
## Tools Used
- Power BI
- Microsoft Excel
- Data Visualization
- Data Cleaning
- DAX
- Power Query

## Key Insights
- Loan applications increase steadily throughout the year.
- Most customers choose 36-month loan terms.
- Debt Consolidation is the most common loan purpose.
- Rent and Mortgage customers account for the majority of applications.
- Good loans significantly outperform bad loans.
