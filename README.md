# Bank Loan Analytics Dashboard
## Project Overview
This project presents an interactive Power BI dashboard designed to analyze bank loan performance, customer lending behavior, funding trends, and repayment insights.
The dashboard enables users to monitor loan applications, funded amounts, repayments, interest rates, and customer financial metrics using interactive visualizations.
---
## Dashboard Features
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio
- Monthly Loan Application Trend
- Loan Applications by State
- Loan Applications by Purpose
- Loan Applications by Home Ownership
- Loan Applications by Loan Term
- Interactive Filters and Navigation
